## 架构

- ConnectionSession独立拥有传输、解析器、采样/报文/图像、统计、记录和发送调度。切换显示不停止其他连接。
- DataEvent包含connection_id、generation、sequence、软件时间和payload；拒绝过期排队信号。
- DecodedFrameEvent保留协议ID/revision、原始字节、有类型字段、字段区间和校验结果。一次解析供字段视图/波形/规则消费。
- DeviceProfile保存连接要求、接收定义、通道映射、发送操作、参数与超时；预览与实时共用编解码。
- SendRequest明确目标连接/generation/job_id/origin/实际字节；任务冻结目标和配置，不读取当前选中行决定发送。
- 原始数据不受显示换算或派生处理修改。最多16通道、10万点历史；绘图合并不能成为丢采样借口。
- 同COM继续与ISP互斥，真正关闭后才释放租约。只读SWD/预览/回放永不获得真实发送能力。

## 各阶段细则

M1：先保持单连接行为，再引入四连接设备树；独立接收/解析/记录/报错，稳定ID绑定卡片/命令/任务，删除前列影响。统一用户配置保存最近工作区、发送历史、档案/模板/窗口；与updates已有设置共用边界而非互相覆盖。重连默认关，仅允许可靠身份，歧义停止，不恢复发送许可。

M2：字段列表/排序/类型/字节序/位域/枚举/数组/消息分支/校验范围与高级JSON共用模型；无效草稿不替换活动配置。字段与原始字节双向高亮，解释长度与校验错误。精确整数保留在详情，有损float映射明确报错；数组显式选通道。私有预览沿用4KiB/500ms/256帧，不打开设备、不发送、不污染正式解析器。接收定义不宣称任意可逆编码。

M3：模板支持参数类型/范围/默认值/生成预览/复制/导入导出；旧快照不改，新引用在任务开始冻结revision和参数。支持发送后等待有效响应、成功/超时/取消。失效引用禁止执行，删除列引用数。同连接手动/周期/文件/控件/工作流互斥，不同连接独立。未知部分写入/断线/错误应答停止不重试。

M4：原文件和格式保留，不强换数据库。会话目录列来源、时间、数量、完整性和路径；旁路索引可重建，文件变更失效。seek重建解码状态并增加回放代次，支持时间定位/暂停/速度/循环。新记录用明确新版来源字段、兼容旧版。回放TX不重发，暂停显示继续采集与记录。

M5：先纯执行核心后原生Qt节点编辑器。节点包含Source/Select/Math/String/Filter/FFT/Condition/Delay/Template/Send/Wait/End；编译验证端口、缺失引用、循环。仅有界重复，维护滤波状态。复用NumPy和现有分析，支持移动平均/指数平滑/FIR/biquad及常用数学，FFT窗口和Magnitude/Power/PSD/dB明确；无可靠采样率不伪造Hz轴。派生数据保留来源和修订。自动发送默认不启用；manual/timer/onChange，首次onChange只建基线；10包/s、累计1000包或5min任一达到即停，单包16KiB。断线/代次变化/ISP占用/队列满/停止立即撤销后续请求。

M6：配置撤销覆盖档案/模板/节点/连线/页面/卡片，最多200步加内存预算，连续拖动合并，分支编辑丢弃redo。撤销不执行硬件动作。默认布局不变，增加拆分/合并/浮动/恢复，工作流独立页。写schema9读1–8，旧单源为默认连接，绑定不漂移；不保存自动连接/发送/擦写许可。原子存储，并发冲突拒绝静默覆盖。
