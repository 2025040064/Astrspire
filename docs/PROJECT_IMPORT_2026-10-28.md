- 便携 EXE 与根目录启动器错误套用 `versions/<version>` 的父目录层级：先得到 3 项失败，再按实际布局修复。
- 源码包漏 tests/examples/firmware/开发配置且未排除潜在密钥：先得到失败测试，再补完整 allowlist 与排除规则。无分发许可凭据的本地字体不进入公开源码包或 Git。
- 更新源仍指向尚未创建的 Astrspire-Releases：先得到失败测试，再统一为用户已批准的新公开仓库 Astrspire，不自动发布 Release。
- 安装器默认指向 C 盘用户目录、业务日志仍写版本目录：各自复现失败后，改为安装包旁的默认目录和统一 `data/local/logs`。更新和已有安装仍保留显式原路径。
- dev5 缺失工作流编辑模块：补齐独立原生 Qt 编辑器及显式运行/停止、草稿/撤销、来源与发送守卫；相关 36 项测试通过。这不等于 dev5 全量接入主窗口，多连接/工作区 schema9 等计划仍未完成。

- 干净源码首轮测试暴露对原版 ZIP 的隐式依赖：保留原始资料比对作为可选测试，另增两项公开 HEX 样例固定回归，不上传原版工具。
- 回放测试曾在 Python 线程结束后、Qt 队列尚未交付最后帧时断言失败：确认回放会发送尾批后，修正测试等待交付完成，不缩短数据或放宽样例断言。相关 29 项通过。
