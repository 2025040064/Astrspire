# Astrspire v0.6.0-dev3 功能与限制

- 既有STC89C52RC F002 / `66 43 FD`烧录核保持不变；未知芯片/版本在擦除前拒绝。不是全芯片烧录器。
- 新增SWD数据源：ST-LINK/CMSIS-DAP、G431/F103配置、受限ELF清单、运行中SRAM读取、序号/重试/覆盖统计、停止回收。本轮仅支持自有HAL测试采样区，不支持任意内存命令。
- SWD接入既有多卡波形/分析/基础测量/CSV；不进行UART发送。所有发送入口关闭。正常显示、暂停和记录仍独立。
- SerialWeb的编码和行分帧函数已移植到Python；UTF-8/GBK/Latin-1/ASCII/UTF-16LE显示，手动发送遵循所选编码，不可无损表示时拒绝。HEX继续严格字节对，不复刻上游宽松清洗。
- 共享只读绘图视图复用窗口峰值、保留端点及NaN缺口；不减少10万点历史，不改变记录和测量数组。
- schema7读写，兼容1–6；不自动连接、发送、启动OpenOCD或读取外部采集清单。
- 未移植SerialWeb网页、自动重连/自动应答、可视化协议编辑和专有工程格式；未新增STM32烧录界面、STC选项/EEPROM或供电控制。
- STC块ACK、全片回读和冷启动运行是不同证据；SWD采集不是串口接收或ADC实测。

实际测试数、性能和分板结果以validation-v060-dev3.md及hardware-v060-dev3.md为准。SerialWeb代码受AGPL-3.0约束，来源与许可证随源码和EXE交付。
