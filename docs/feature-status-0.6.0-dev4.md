# Astrspire v0.6.0-dev4 功能与边界

当前开发范围：STC89C52RC既有指纹下载、串口助手、基础软件示波器。不是全芯片烧录器、硬件电压示波器或完整VOFA/Lissio移植。

新增源码能力：

- 独立RX/TX及命令/控件编码，严格HEX前缀/分隔符，CR/TAB，发送字节预览和20条成功手动历史。
- 有界原始块视图、HEX/ASCII/偏移、文本/HEX/限时字节正则、文件搜索、快照与追底。
- 声明式流式分帧、命名CRC、私有被动预览、独立发送模板及命令快照。
- 连接预设、协议草稿和预设的配置撤销重做。
- 原始流与文本分卷、会话清单、旧记录兼容及RX-only回放。
- 工作区schema8读取1–7，命令文件schema2读取1。
- STC8KiB用户程序区独立擦除、下载前可选预擦均已取得本轮实板ACK证据。已有全流程仍只对应严格F002 / 66 43 FD，不扩大芯片支持范围，未做全区空白回读。

保留：单接收链路、16通道/10万点、共享采样与PyQtGraph、测量、图像/分析/控件、端口互斥与异常停止。界面过滤不改变记录、测量或原始采样。

未实现：多连接、CAN、工业协议、AI、完整节点图、自动应答、任意用户脚本、STM32烧录、新芯片族、EEPROM/选项写入、全片空白回读。

验证状态以 validation-v060-dev4.md 的最终记录为准。STC本轮重新匹配CH340和F002 / 66 43 FD，实测8KiB擦除请求及ACK，并完成全区预擦后的512字节传输；不能把ACK称为全区空白回读或用户程序运行验证。G431串口此前无有效回复，本轮不据离线或回环结果宣称已修通接线。
