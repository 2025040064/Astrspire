# v0.3.0 功能状态

日期：2026-10-22。本文记录源码实施范围，不代表全部功能已验收；不是“官方完整工程已逆向移植”的声明。

STC 对齐指定 AiCube v6.97A 的功能目标；STM32 使用通用数据调试能力，不含烧录。界面和功能均为自有实现，不复制官方代码及素材。

## 源码覆盖与限制

| 区域 | 已编写能力 | 当前边界 |
|---|---|---|
| UI | VOFA 风格白蓝侧栏、波形/日志与右侧数据，浅色/深色主题 | 自有素材，不宣称像素级完全复刻；本轮未完整运行验收 |
| UI | 主要横向/纵向区域原生拖动分隔 | 移除常驻说明段落与“工作模式”整块；下载模拟在工具菜单 |
| STC | 1345 项静态型号目录和搜索 | 不证明 GUI 目录穷尽，不代表全型号可烧录 |
| STC | HEX 校验、BIN 基址、缓冲区查看、HEX/BIN 新文件导出 | BIN 空洞补 FF 是文件规则；已知 STC89C52RC/LE52RC 限 8 KiB，未知容量不推定可写 |
| STC | EEPROM 文件载入、查看、导出 | 仅文件缓冲区，不读写设备 EEPROM |
| STC | 枚举、同进程独占、2400/8N1 + 7F 只读识别 | 识别不是下载；打开 COM 可能影响 DTR/RTS；本轮未新增硬件验收 |
| STC | F002 / 6.6C 真下载核与 GUI 显式入口 | 仅严格 F002 / `66 43 FD`、STC89C52RC/LE52RC；不扩展到全部目录；块 ACK 不等于全片回读 |
| STC | 模拟下载、官方会话离线回放 | 不连接真实设备；不得称为本轮实机成功 |
| 数据源 | 手动串口连接/断开 | 显式选择端口和参数；监视与 ISP 互斥；连接不自动发送 |
| 数据源 | TCP 客户端、TCP 服务器、UDP | 显式 IPv4/端口与启动；监听不等于已连接可发送，UDP 发送需对端；不声称已实网验收 |
| 数据源 | CSV 流式回放 | 暂停/恢复、0.1–20 倍速、循环和进度；不打开串口或发送设备数据 |
| 引擎 | FireWater / JustFloat / RawData | 自有流式解析，不宣称支持所有私有格式 |
| 显示 | 16 通道波形、显隐、缩放/平移/游标、暂停、缓存/时间步长 | 显示暂停不等于停止采集 |
| 显示 | 实时数值、0–12 位小数、数值/仪表/按钮控件 | 按钮仅用户点击后请求发送；不含摇杆、图像/立方体 |
| 记录 | 实时 CSV、最近采样导出、方向日志 | 显式选择路径；TX 已交驱动不代表设备 ACK |
| 命令 | 添加、选中发送、JSON 保存/载入、清空确认 | 自有格式；载入/选择不自动发送 |
| 发送 | UTF-8/HEX、结束符、手动开启周期 | 需可发送数据源；断开/失败不自动重试 |
| 发送任务 | 原始文件分包发送 | 非空普通文件最大 16 MiB；界面默认 1024 字节/包、20 ms；进度仅计入队字节 |
| 发送任务 | 命令列表顺序/重复发送 | 重复 1–10000 次、间隔 20–60000 ms；进度仅计入队包数；不是固件下载协议 |
| 配置 | 工作区 schema 3，兼容 schema 1/2 | 保存源、主题、通道、波形、发送输入和数据区分隔尺寸；不恢复连接、回放或发送 |
| 配置 | 独立控件配置 JSON | 载入不触发按钮；不等于 VOFA 原生工程/插件兼容 |
| 构建 | 默认 onedir、可选 onefile v0.3.0 | 本轮 onefile 构建完成；未启动/复测；本机 F 固定解包目录，跨机迁移未验证 |

文件与顺序发送必须用户显式开始，不随配置载入而启动。断开或关闭窗口停止任务，显式取消清待发队列，自然完成保留最后包；已发送内容无法撤回。
