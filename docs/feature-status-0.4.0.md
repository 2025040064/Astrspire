## 证据层级

- REA安装目标、方法和Evidence ID见 `analysis/10-vofa-static-feature-inventory-2026-10-22.md`。
- 本轮确认的是安装版本中的静态接口、图像分派、Demo输入/转换链；没有运行原软件、连接设备或抓取新通信。
- 自有FFT、滤镜、布局、CSV/JSON及错误边界是独立设计，不能倒写成逆向恢复的原算法。
- 全芯片工作已按用户最新要求暂停；本表不是芯片支持表。
