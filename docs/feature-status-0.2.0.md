# v0.2.0 功能状态

日期：2026-10-21。目标仍是 STC 功能对齐指定 AiCube v6.97A、STM32 数据调试对齐 VOFA+ 1.3.10；STM32 不含烧录。

本表是实施状态，不是“官方全功能已完整逆向”的声明。不把静态目录、模拟、离线帧一致或官方工具的成功当作自研硬件验收。

## 接下来实际需要的验收

1. 只读识别已完成实板对照（A1）；未知版本分支仍需其他芯片样本，当前只有离线测试。
2. F002 已完成实板写入、官方逐消息对照、GUI 二次确认入口和重启运行验收（A2）；其他型号/协议族仍需分别取证与实板验收。
3. 对其他型号/协议族分别获取身份、布局和通信证据；目录不直接变成支持列表。
4. 实际设备串口收发与连续记录、不同 DPI 布局验收；插件和网络功能按独立里程碑实施。
