# Astrspire v0.5.0 功能边界

基准：VOFA+ 1.3.10 已有静态分析、用户截图和配置。独立实现，不包含官方程序、代码、商标图片或插件。不是完整等效的 VOFA 克隆。

| 功能 | 本版实现 | 限制 |
|---|---|---|
| 原始采样 | 单一有界100000帧存储，最多256原始通道；页面显示前16 | 软件接收时间不是设备采样时间 |
| 时间与导出 | CSV/原始记录保留来源时间；CSV微秒时间、原值和名称 | 本机记录格式，不宣称原生格式兼容 |
| 接收可靠性 | 256事件拆批、确认背压；已读块不静默截断 | 串口驱动/设备是否丢帧仍须序号测试 |
| 记录 | CSV、原始RX/TX、监视文本日志独立写线程，有界队列 | 满队列/磁盘失败停止对应记录并显示未保存数；flush不是fsync |
| 用户页面 | 新增、命名、复制、拖动/菜单排序、删除；混合波形/控件/图像/分析，分隔条拉伸 | 最多32页、每页64卡；只保存布局，不保存采样历史 |
| 稳定绑定 | 页面、卡片、控件、命令组及命令有稳定ID | 控件自带显式发送载荷，不读取或执行外部脚本 |
| 命令组 | 新增、命名、排序、删除、发送本组；序列冻结值快照 | 32组、每组64条；入队/驱动完成不等于设备ACK |
| 工作区 | 自有schema5，兼容schema1–4迁移；当前页面、命令组、Demo配置 | 恢复不连接、不发送；3D模型仅显式载入 |
| 原生工程 | 检查→字段诊断/映射预览→用户应用；明确选择部分导入 | 非空原生页面/命令组无结构证据，仍不支持；未知连接/编码不替代 |
| VOFA Demo兼容 | CSV整文件/JPG单图，自然排序、独立周期/循环/暂停/停止，可并行 | 暂停在当前文件边界生效；非法数字报错；只支持已观察FW/JF封装 |
| 保留功能 | 串口/TCP/UDP、三种数值引擎、波形/XY/FFT/直方图、13类控件、图像和20显示效果 | 部分效果为近似；3D线框、SGR终端，不等于完整原生三维/VT100 |
| STC ISP | 保留F002 /66 43 FD既有指纹和下载核 | 本轮用户无恢复HEX，硬件验收不擦写；不扩大芯片 |

当前软件、产物及三板结果分别见 `validation-v050.md`、`hardware-v050.md`。只有实际执行且通过的检查标记通过，源码覆盖不代替实机验证。

暂不实现：STM32烧录界面、全STC芯片扩展、原生Qt5 DLL/QML插件ABI、未知原生工程结构、滤镜逐像素等效及完整VT100。
