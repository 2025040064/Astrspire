# Astrspire v0.5.1 功能边界

本版在v0.5.0基础上修复多卡页使用流程，独立实现，不包含VOFA+或AiCube的专有代码、界面资源及插件。不是完整VOFA等效版本。

## 本版操作规则

- 每张波形卡标题旁有“操作此卡”。顶部明确显示操作目标；暂停、缓冲点数、网格、线宽、坐标轴、XY、颜色和PNG导出作用于该波形卡。没有目标或删除已选卡后禁用，不自动转移操作对象。切到另一页时选择该页首张波形，可再手动切换。
- 通道名称、显示换算和Δt为共享设置；颜色、显隐、模式、XY绑定、线宽、网格、坐标轴、显示容量为各卡独立设置。原始SampleStore仍独立保留最多100000帧，不因某卡容量缩小而缩短原始历史。新建波形卡默认显示容量100000点。
- 自有工作区写入schema6，读取schema1–5。保存各卡完整显示配置，不恢复连接、发送、采集历史或运行暂停状态。旧版软件不能读取schema6；应保留旧工程文件，需要回退时用旧文件。
- 新分析卡可选择同页波形稳定ID，沿用其暂停快照、显隐及Δt；也可显式选择共享实时数据，后者不随波形暂停。复制页面重建内部引用，删除来源显示“关联波形已删除（无数据）”，不自动换源。
- 默认和新增控件卡复用完整属性编辑器；右键编辑/前移/后移/删除，控件ID保持不变，参数更改不会发送。
- 各图像卡分别保存自己的图像；JPEG/PNG保存源字节，不含显示效果；原始像素图保存当前视图PNG。取消/无图不保存，不覆盖已有文件。
- 未命名通道统一从CH1开始，内部索引仍从0开始。显式名称CH0及文件来源名称保留。CSV默认名称与界面一致。
- 原生工程导入列出已支持、明确忽略、未支持和错误的字段路径。未知字段、未映射xoffset及非空原生卡页/命令组不计作完整导入，必须明确选择部分导入。只读检查不修改当前工程。

## 保持不变与未完成

v0.5.0的串口/TCP/UDP、三种数值引擎、波形/FFT/直方图、13类控件、20种自主图像效果、异步记录、CSV/JPG并行Demo、命令组与严格STC指纹仍保留。详见[前版功能表](feature-status-0.5.0.md)。

以下没有在本版完成：多卡10万帧增量投影优化、滤镜算法/完整参数及动画等效、控件对命令库ID引用、原生非空页面/命令组映射、完整三维/VT100、原生Qt5插件ABI。性能不以自动化测试通过代替吞吐验收。

不扩展STC芯片，不新增STM32烧录界面，本轮不访问硬件、不刷板。STC无恢复HEX；STM32只有ST-LINK、无数据连接。旧板卡报告不能当本版实测结果。

本轮测试与构建记录见[验证记录](validation-v051.md)；只有实际完成的项目标通过。
