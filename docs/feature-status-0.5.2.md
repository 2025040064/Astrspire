# Astrspire v0.5.2 · 大波形界面小版本

本版只调整界面，沿用schema6和现有收发/烧录逻辑，不增加设备能力。

- 中央默认波形75%、终端25%；小窗口优先保证控件不被裁切。左右栏位置保持不变。
- 工具移到画布底部，宽窗口一行、窄窗口两行；顶部不再重复多行标题和操作栏。操作目标仍为选中的波形卡。
- 终端收发始终可见；周期发送开关与周期在终端右上角菜单内，只有手动启用才发送。任务运行/错误时显示进度。
- 分隔条仍可拖动、方向键调节、双击/Home恢复新的默认比例；加载旧工程尊重其已保存尺寸，不自动重排。
- 工作区仍写schema6、读schema1–6。不是完整VOFA等效版本。

## 已知未修复项

控件位于波形之前可能使波形只显示1点；实时更新可能清除固定轴；分析刷新可能落后一个批次；自定义波形恢复暂停需新刷新。图像修改未标脏、原生导入部分非法值漏报、复古强度和海报化量化问题仍未修复。多卡性能与命令库绑定未实施。这些属于后续任务，不能因本版测试通过而标记解决。

没有刷板，不扩展STC芯片，不新增STM32烧录UI。onefile仍采用本机F盘解包路径，无F盘电脑未验证。验证结果见validation-v052.md。
