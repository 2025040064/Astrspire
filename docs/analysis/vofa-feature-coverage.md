## 本项目接口与安全边界

`qx_stc_isp.vofa.create_decoder(name)` 产生仅处理输入字节的解码器；`feed(bytes)` 返回含原始字节、数值通道或错误的 `TelemetryEvent`。`MonitorSession` 只接收调用方已打开的 `PassiveByteSource`，仅调用 `read_some` 和 `close`，不含发送入口。`CsvRecorder` 只在显式 `open()` 后创建文件，且不覆盖已有文件；`save_workspace` 仅保存端口名称、可为空的波特率、解析格式和通道名，`load_workspace` 不打开串口。用户未选择波特率时不猜测默认值。

编解码器的 UTF-8 文本替换、非有限数拒绝、缓冲长度上限及坏帧恢复是本项目防护选择；不能由安装包元数据推导为原程序实现。

4. 离线测试源文件为 `tests/test_vofa_core.py`；按本轮约束尚未执行，不能报告通过数量。
