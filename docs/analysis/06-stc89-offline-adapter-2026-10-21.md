# STC89 字段适配与官方会话离线回放

历史离线适配阶段。后续时钟计算、只读识别及受限下载核心见 [07 核心证据](07-stc89-core-evidence.md)；下文的未完成项以该报告和当前代码为准。

## 本轮交付

- `framing.FrameStreamDecoder`：有界分片重组，允许有限帧前噪声；识别帧头后的长度、校验和结束符错误直接失败，不跳过坏帧继续。
- `stc89.Stc89Status`：解析本次 53 字节状态 payload、8 个时钟测量值、芯片 ID 和版本。只接受 F002 与 `66 43 FD` 配置指纹；前两个字节表示 6.6C，第三字节仍保留为附加字段。
- `stc89` 纯字段函数：解析已捕获的协商参数、构造访问准备包、按 512 字节计算擦除参数、构造 8 KiB 程序区内对齐的 128 字节写块并严格核对写 ACK。不执行设备 I/O。
- `official_replay.OfficialCapture`：核对原始记录 SHA-256，重组 RX，独立重建并对照全部 TX、当前 HEX 及每个 ACK；预检查全部成功后才创建回放步骤。
- `OfficialReplaySession`：复用 `SessionEvent` / `SessionState`，在线程中更新进度和日志，支持取消，完成文案明确为离线回放。
- GUI 新增“离线回放官方抓包…”：选择 `STC89C52RC/LE52RC`、加载 `led.hex`，再选择 `captures/private/aicube-com8-20261021-1646.jsonl`。不需要连接开发板，真实串口下载仍禁用。

## 未确认项及下一阶段

1. 通用波特率 reload 计算涉及时钟测量和浮点转换，尚未完整独立重建；当前只解析已捕获参数，不将 `FF FD` 当作任意设备的通用数值。

3. 块 ACK 不是全片回读；FF/82 后未观察到 RX，不新增结束 ACK。
4. 第三版本邻接字段、准备包全部语义与 81 特殊应答仍待确认。
