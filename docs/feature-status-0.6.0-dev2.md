# Astrspire v0.6.0-dev2 · 功能与边界

## 三个用途

- STC烧录：保留既有STC89C52RC/LE52RC、ID F002、Bootloader原始字段`66 43 FD`的下载核。具备HEX检查、冷启动等待、识别、块应答、进度、取消与错误收口。未知身份在擦除前拒绝，不新增EEPROM、选项字节或自动供电控制；静态芯片目录不是可烧录列表。
- 串口助手：手动连接、文本/HEX收发、编码与结束符、周期/文件/命令组发送、收发日志与显式数据记录。端口忙或拔出报错后停止，失败不盲重试；同COM的ISP与监视互斥。恢复工程、切页和接收反馈不自动发送。
- 基础软件示波器：PyQtGraph 0.14.0，最多16通道/100000点，时间/XY、显隐、暂停快照、缩放/平移、游标、固定轴、颜色和PNG导出。右栏测量时间波形可见窗口的有效点数、最小/最大、均值、峰峰值和RMS。原始记录不受显示换算/降采样影响。

## 使用边界

软件显示单片机发送的采样，不直接测量引脚电压。横轴使用设定Δt，不是自动测得的设备时钟；未配置单位时不标电压。测量最多5Hz，暂停冻结，隐藏停止计算；空数据不显示假零，峰峰值溢出有明确状态。

沿用schema6，可读取既有1–5，保留已存页面和布局。现有图像、分析、命令组继续保留，不新增命令库动态绑定；不加入触发、单次捕获、自动频率测量、STM32烧录、全芯片支持或原生Qt5插件兼容，也不宣称完整VOFA移植。

## 已有证据

763项离线回归通过；60秒/2500帧每秒本机TCP回环收齐150000帧，CSV450000行逐项一致，线程正常退出。100000点/三卡：单通道投影到离屏渲染稳态中位值约28.2ms；16通道约254.1ms，初次显示约865ms。16通道高负载仍可能不够流畅，不将单通道性能推广到全部通道。

10分钟/2500帧每秒本机TCP回环1500000帧、CSV4500000行逐项一致，15项检查通过，记录无未保存帧。硬件另测：COM9只读识别F002/6.6C成功，未擦写；COM7在115200/8N1只读监听10秒无数据，未完成STM32波形实测。完整证据见`validation-v060-dev2.md`和`hardware-v060-dev2.md`。历史A2仅证明严格指纹和当时HEX的下载结果，不算本轮重新烧录；无恢复HEX的STC不擦写。
