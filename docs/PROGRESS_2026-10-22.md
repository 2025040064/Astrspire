## 2. 已编写内容

### 界面

- 自有白蓝界面：图标导航、紧凑侧栏、中央波形/日志、右侧实时数据；不复制 VOFA+ 官方代码或素材。
- 移除常驻说明段落及“工作模式”整块；保留必要状态、错误和实际行为提示，下载模拟改由工具菜单进入。
- ISP 参数/输出、状态/日志，数据侧栏/中心/数据列与波形/日志采用原生拖动分隔；新增浅色/深色主题。

### 数据源、控件与配置

- 串口显式连接；TCP 客户端、TCP 服务器、UDP 显式 IPv4/端口配置与启动。服务器监听不等于对端已连接；UDP 发送需要对端。
- CSV 流式回放、暂停/恢复、0.1–20 倍速、循环和进度；不连接串口、不发送设备数据。
- FireWater / JustFloat / RawData，16 通道波形、显隐、缩放、平移、游标、显示暂停、缓存和时间步长。
- 数值/仪表通道绑定、手动按钮控件及独立 JSON 控件配置。命令列表支持添加、选中发送、JSON 保存/载入和清空确认。
- 工作区升级为自有 schema 3，兼容 1/2，保存数据源、网络地址/端口、CSV 配置、主题、精度、显示格式、通道/波形/发送输入和主要数据区分隔尺寸。载入不自动连接、回放或恢复发送；不声明兼容 VOFA 原生工程格式。
- CSV 通道名随采样保留用于记录/导出；针对名称填充长度问题已调整 GUI，未复跑确认。

### 发送任务

- `SendJobController` 已接入原始文件分包、命令列表顺序/重复发送。控制器构造与配置载入不发包；只有用户在可发送数据源上显式开始才运行。
- 文件须为非空普通文件，最大 16 MiB；界面默认 1024 字节/包、20 ms。原始文件发送不是 STC/STM32 烧录，不代替 ISP 协议。
- 顺序发送重复 1–10000 次，间隔 20–60000 ms；文件/顺序任务与周期发送不能同时运行。
- 进度为已入队字节/包数，**不是设备 ACK、接收、执行或写入成功**。
- 断开或关闭窗口停止任务；显式取消清待发队列，自然完成保留最后包。停止无法撤回已经发送的数据；失败不自动重试。
- 这些发送任务在停止测试要求后接入，尚未测试。

### 构建和存储

- 默认 onedir 输出 `dist/Astrspire-v0.3.0/`；`-OneFile` 输出已构建的单文件 EXE。
- 构建缓存/临时文件使用 F 工程；onefile 运行解包路径固定为本机工程的 `build-preview/runtime-v030/bundle-run`。跨机器路径可用性和可迁移性未验证，不能宣称通用便携。
- 日志默认跟随源码工程或 EXE 目录的 `logs`；工程、EXE、导出、依赖缓存和运行临时目录保持在 F 盘。本轮不主动新建 C 盘项目副本或缓存。
- 未计算新包 SHA、未做追加归档检查、未启动新包，避免把构建和校验混为一谈。

## 4. 保留限制

- 静态 1345 型号不等于可烧录列表；仅 F002 / `66 43 FD`、STC89C52RC/LE52RC 注册真实下载核。其他族不共用 STC89 帧格式，未知指纹拒绝擦写。
- 不修改选项字节、读写保护，不写设备 EEPROM，不自动控制 DTR 供电；打开 COM 仍可能改变 DTR/RTS。
- 同一 COM 的监视与 ISP 同进程互斥；连接/配置载入不自动发送，周期/文件/顺序/按钮发送均须显式操作。
- JPG 回放、摇杆、图像/立方体、VOFA 原生插件、原生工程兼容及全部功能对齐未实现。
- STM32 不含 UART ISP、ST-LINK 或官方下载工具集成。
