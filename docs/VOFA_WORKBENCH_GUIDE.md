# Astrspire 数据工作台使用说明 · v0.6.0-dev3

## dev3：SWD与串口编码

数据接口选择“SWD 内存采集”，填写探针类型、精确序列号、芯片系列，并选择本轮HAL固件生成的capture.json。点击连接才启动采集；不是UART，没有波特率，不支持发送。默认50ms轮询、固件100帧/秒，横轴Δt置10ms。CH1为设备序号、CH2为板端毫秒，其余为已知测试信号；不代表引脚电压。探针拔出、身份/固件布局不符或设备重启会停止，不自动重试。

OpenOCD需合法安装并设置ASTRSPIRE_OPENOCD/ASTRSPIRE_OPENOCD_SCRIPTS；采集期间不暂停或复位目标，不写SRAM/Flash，不运行从工作区导入的命令。仅实验脚本负责授权的测试固件刷写/恢复，软件没有STM32下载按钮。

终端菜单“文本接收编码”也控制手动文本发送编码，增加ASCII和UTF-16LE。不能无损编码时拒绝发送；HEX仍按原始字节处理。分帧支持CR、LF、CRLF及跨读取边界。编码/分帧移植自SerialWeb，许可与来源在third_party/SerialWeb。

schema7保存SWD配置，可读取schema1–6。载入只恢复字段，不连接、不读取清单、不发送。下面dev2及更早说明为历史；当前能力与实测限制见dev3状态报告。

## 开发预览说明

保留白蓝界面和中央75:25大波形布局。dev2使用PyQtGraph绘图，并增加右栏“测量”页；多卡复用后台生成的只读数组。已有保存工程仍为schema6。聚焦既有STC89C52RC烧录、串口助手和基础软件示波器，不提供STM32烧录。命令库引用和新动态模板未纳入本阶段；实际测试与硬件结果见功能状态和独立验证报告。

## 基础测量

点击时间波形卡标题旁“操作此卡”，在右栏选择“测量”。每个可见通道显示有效点数N、最小值、最大值、平均值、峰峰值和RMS；点击通道前的箭头展开。统计包含通道比例/偏移，单位沿用通道配置，不默认代表电压。

滚轮、拖动或固定时间轴改变统计窗口。测量使用窗口内全部显示采样而非绘图降采样点，最多每秒5次；切到其他页停止计算。暂停波形后保留冻结统计，恢复后跟随数据。空窗口显示“无有效采样”，溢出显示“超出范围”。XY可正常绘图，但本测量页不对XY按时间窗口统计。

横轴仍按用户设定Δt换算秒；它不是自动测得的设备采样时间。软件示波器不能代替硬件示波器探头，必须先让单片机发送可解析的采样数据。

## v0.5.2 沿用操作说明

中央默认75%波形、25%终端；工具条在图下方，窄窗口自动换成两行。点击卡片标题旁“操作此卡”选择波形，底部工具和右侧显隐操作该卡；Δt及名称/换算是共享设置。拖动分隔条调整，双击或聚焦后Home恢复默认布局，旧工程载入保持原保存比例。

周期发送设置位于终端右上角菜单中，不因打开菜单而启动发送。收发输入保留，任务进度和错误会展开显示。工作区仍为schema6，兼容1–5；下面较早版本的schema说明属于历史记录。已知数据/图像/导入问题见本版功能与限制，未在本次界面调整中修复。

以下为已有功能使用参考，不表示完成全部原版等效。端口号只是历史候选，使用前须重新枚举并确认设备。

STC下载与数据调试是两个工作区；STM32不提供烧录。COM8/COM7仅为历史设备记录，不是固定分配；每次使用前重新枚举并确认板卡，不能仅凭COM号判断芯片。

软件工具菜单“使用帮助”或F1可查看本说明及功能状态，文档随EXE打包；帮助页不会自动打开网络链接。

界面字体使用随包加载的苹方 SC（Regular/Medium/Bold）；系统装有 SF Pro 时拉丁字符优先 SF Pro，否则用苹方，最后回退微软雅黑。

## 不接设备先看界面

1. 左侧选择数据工作区，在“数据来源”选择合成 Demo，设置通道数、周期、幅值、偏移，然后手动开始。
2. 中间“波形”可滚轮缩放、拖动平移；Home自动适应、Space暂停显示、Esc取消当前拖动。暂停显示不暂停接收或记录。
3. “显示设置”选择时间/XY、绑定XY通道、网格、线宽、成对固定轴范围。时间轴用秒，XY用通道显示值。
4. 右侧勾选通道控制显隐；在通道复选框上右键，可改曲线颜色和通道参数。全局名称列表用英文逗号；中间留空的位置保留CH编号，不再前移后续名称。
5. “统计 / 频谱”切换最新柱状图、直方图、幅度频谱；选择单个通道、分桶数、FFT窗口、窗函数及去直流。FFT使用最新可用二次幂点数，最低8点，不补零、不跨缺失值插值。频率使用设置的Δt，不是自动测得的设备采样率。

## 通道显示换算

- `显示值 = 原始值 × a + b`。名称、单位、比例、偏移和独立精度可随工作区保存。
- 波形、统计、右侧数值和接收控件使用显示值；原始采样CSV、原始TX/RX、解析日志不被改写。
- 修改参数从共享原始历史重建显示，最多保留100000帧；每张波形可选择更小显示上限。固定轴保持原设置，已淘汰历史不能恢复。
- 控件自己的手动输入量程和命令模板独立，不自动反算a/b。换算溢出时保留原始记录，但不把该帧画成有效数据。

## 控件

- 左侧控件页或中间“+”新增；表单可配置量程、步进、通道、小数、长按时间、四元数等，特殊参数仍可用附加JSON。姿态控件可填写本地 .stl/.obj 路径（≤4 MiB、≤4000 面），读取失败显示立方体；不会访问网络。
- 控件右键编辑、前移、后移或确认删除。接收反馈和载入布局只更新外观，不触发发送。
- 文本/HEX和结束符在控件参数中选择。滑块/旋钮用`set:{value:.2f}`，摇杆用`joy:{x},{y}`；HEX整数例`AA {value:02X}`。不支持表达式、属性、下标或任意代码。
- 按钮勾选分沿模式后，分别填写按下和松开命令，主模板被忽略。松开命令只在确实按下后正常释放时触发；Esc、失焦、隐藏、禁用、删除只取消，不暗发释放。
- 长按按钮显示本地百分比，到达设置时间且仍按住时发一次；提前释放或失焦取消。摇杆可设本地回中，但不会自动发送零值。
- 指示灯支持单阈值或三色区间。三色规则为小于下阈值、下阈值到上阈值之间、大于等于上阈值；反向判断交换低/高颜色。附加JSON可设置`low_color`/`middle_color`/`high_color`/`on_color`，格式为`#RRGGBB`。这是本软件的明确规则，不声称原生边界完全一致。
- 仅手动连接且没有其他发送任务时，发送类控件才可用。载入工作区不恢复周期、任务或连接。
- “图像卡片”可选择本地图片或实时索引0–15。实时卡片只读取共享缓存，隐藏时不解码，不发送数据；无帧/坏图时显示占位。独立“图像”页仍提供滤镜/旋转，卡片默认不套用这些显示设置。保存/载入工作区只恢复来源与索引，不恢复图像载荷或设备连接。

### 移动和拉伸

选择“自由布局”并勾选“编辑布局”。拖动右上角角标移动，拖动右下角拉伸；选中角标后方向键每次8像素，Esc取消当前拖动。↶/↷撤销、重做最近最多64步位置/尺寸操作；删除/替换控件或载入配置会清除布局操作历史。编辑布局时发送控件禁用。取消编辑可正常操作控件；切回自适应不会清除已保存的自由位置。

本软件限制每区最多24控件、坐标0–8000、宽160–2000、高80–2000；实际最小尺寸还受控件内容约束。大画布可滚动。控件独立文件使用自有schema2，兼容旧schema1；不是VOFA原生控件文件。

## 真实串口和网络

- 串口需手选COM、波特率、数据位/校验/停止位。连接本身不发送应用载荷，打开串口可能改变DTR/RTS。
- TCP客户端/单连接服务器和UDP需显式IPv4/端口。UDP不从来包自动学习发送目标；未指定对端时只能接收。
- 发送框支持文本/HEX、结束符；周期默认关闭。文件分包和命令序列均需手动开始，运行期间不与手动发送交错。
- 入队100%、交给驱动、收到设备确认是不同状态。停止不能撤回已发送字节；错误不自动重试。任何数据发送都不是STC/STM32烧录协议。
- 速率面板统计软件收到的字节/采样帧/图像帧，不是物理链路或芯片采样时钟测量。

## 文件回放

| 来源 | 输入 | 行为 |
|---|---|---|
| CSV回放 | 本软件导出的长格式采样CSV | 按记录时间回放、暂停、0.1–20倍速、循环 |
| Demo CSV数值矩阵 | UTF8纯数字逗号分隔，无表头；文件或目录 | 每行1–16有限数；按设置ms/行播放；JustFloat选项执行float32范围检查 |
| 图像目录 | JPG/JPEG/PNG普通文件目录 | 自然排序、0.1–60fps、暂停/循环；不是向设备发图 |
| 原始记录回放 | 自有qx-stream/version1 JSONL | 按时间和所选引擎重解码RX；TX记录跳过不重发 |

矩阵回放与原生Demo的“按整文件定时送引擎”存在刻意差异；不把本软件的逐行间隔设计称为原生一致。回放不会打开串口或网络。

## 图像引擎

- `ImageStream`为本软件独立连续JPEG/PNG字节流。普通RawData不冒充官方图像解析；勾选独立标准图像流才额外解释图像。
- `FireWaterImage`与`JustFloatImage`来自本轮REA静态证据。前者头为`image:index,N,width,height,type`加LF和N字节载荷；后者为5个LE uint32加两个JustFloat尾，共28字节，然后N字节。
- 类型25BMP、26GIF、27JPG、28PNG、29PBM、30PGM、31PPM、32XBM、33XPM、34SVG；实际解码能力取决于Qt插件。1–24 raw是实验适配，不保证Qt5/Qt6颜色/枚举完整一致。
- 索引0–15由下拉选择；payload缓存32MiB，解码/共享显示缓存另64MiB；每载荷最多8MiB、实际图像最多1600万像素。SVG只接受受限静态子集；GIF不播放动画。
- JustFloat图像模式为识别双尾，普通单尾数值帧需后续4字节前瞻；单独最后一帧可能等待下一批数据。纯数值建议选择普通JustFloat。
- 显示最多约10Hz合并更新，计数仍是收到帧数；可能跳过中间预览。20种效果不是原生shader等效；每种提供一项有界参数（强度/阈值/块大小/伽马/色相/间距/幅度），参数名参考安装包静态观察；强度0返回原图，CPU滤镜使用缩小预览，信息栏显示实际预览尺寸。
- 保存编码图保留原始字节；保存raw图生成当前视图PNG（包含当前效果/旋转）。另“导出载荷”只写原始payload、不含协议头。均拒绝覆盖已有文件。

## 记录、插件、工作区

- 文本接收支持常见 ANSI SGR 颜色、粗体、下划线、256 色和真彩；其他 CSI/OSC 控制序列会被移除，不显示为乱码。不是完整 VT100：光标移动、清屏、回车覆盖等语义未实现。
- 原始收发记录必须手动开始，只对已连接实时来源可用；解析前原始字节按RX/TX记录。CSV保存解析后的原始数值，不做显示a/b换算。
- 原始记录最大128MiB，持久文本日志最大16MiB；达到上限停止对应记录而非伪造写盘成功。终端最多保留3000行显示。
- 工具菜单的数据引擎扩展只接受声明式JSON。`delimited`支持分隔符、前缀、通道数、比例/偏移；`binary_fixed`支持数值类型、大小端、帧头尾、仅载荷sum8/sum16。它们是本项目的规则，不是STC命令，也不是VOFA原生ABI。
- 扩展导入不运行DLL/QML/Python代码。先导入扩展，再选对应`plugin:id`。修改/移除扩展需停止当前数据会话。
- 保存工作区可包含命令、控件、自由位置、引擎、主题、串口与视图参数；不保存连接句柄、发送任务、录制状态或采样历史。载入冲突的扩展/主题会拒绝，不静默覆盖。“导入 VOFA+ 配置”可读取原版 1.3.10 的 `vofa+.config.json` 同目录上下文；包含原生卡页/控件或命令组时拒绝导入，不做静默丢弃。
- 本项目schema4兼容自己的1/2/3；VOFA+ 原生导入只覆盖可验证的设置子集，不声明原生工程无损迁移。旧版独立记录继续作为各自日期的历史证据。

# v0.5.0 新使用流程

- 数据页右上“＋页面”建立用户页，“＋卡片”混合添加波形、控件、图像和统计；标签右键重命名、复制、左右移动或删除，卡片分隔条可拉伸。复制是独立配置，所有页面仍共享同一接收数据。
- 命令侧栏选择命令组，菜单可新增、命名、排序或删除；“发送本组”冻结当时列表，运行中编辑不会改变已开始序列。停止只能撤销尚未发送的内容。
- 数据接口选择“VOFA Demo · CSV + JPG”，分别启用CSV/JPG、目录、周期和循环。可以同时播放并独立暂停/停止；CSV每周期读整个文件，JPG每周期读一张，自然排序。暂停在当前文件完成后生效，不发送设备。
- 保存工作区使用自有schema5。载入schema1–4会迁移旧四页和扁平命令；不会自动连接或发送，也不会自动读3D模型文件。
- 原生工程导入先展示字段路径和未支持数量；默认不应用不完整工程。明确勾选后可只导入已支持设置，无法确认的卡页/命令组不猜测导入。
- 计数区分别显示解析、保留、淘汰、绘图合并和无效。原始历史上限100000帧，显示换算不改原值；软件时间不是设备时间。记录队列满或磁盘失败会停止对应记录并显示未保存数。窗口关闭时会等待线程收尾，未结束时保留窗口。
